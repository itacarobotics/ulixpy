# ulixarm_py

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/itacarobotics/ulixpy/main/install.sh | bash
```

The installer finishes in a shell with the `ulixenv` environment already active.

## Using the environment

In every new terminal, activate the environment before using ulixpy:

```bash
conda activate ulixenv
```

To leave it, run `conda deactivate`.

If `conda` is not found, run `source ~/.bashrc` or open a new terminal.
